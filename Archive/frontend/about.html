Signal Propagation Flow

1. Initiation

User A clicks "Call". The Frontend JS validates inputs and initiates a JsSIP session over Secure WebSocket (WSS:8089) to the Asterisk Engine.

2. Authentication

Asterisk receives the packet. It triggers the res_config_odbc module to query the MariaDB users table. Password hash is verified in real-time.

3. Routing & Dialplan

Asterisk checks extensions.conf. It locates User B's active WebSocket session in memory and bridges the signal.

4. Media Negotiation

Browsers exchange SDP (Session Description Protocol). Codecs (Opus/VP8) are matched. DTLS-SRTP keys are generated for encryption.

5. Peer-to-Peer Stream

Connection established. Audio and Video flow directly between User A and User B via WebRTC. Asterisk logs the duration to the database upon hangup.
